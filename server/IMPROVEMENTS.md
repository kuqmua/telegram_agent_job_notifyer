# Краткий список улучшений проекта

1. Вынести отправку сообщений в Telegram в общий модуль/крейт (`shared`) и убрать дублирование `TelegramMessage`/`sendMessage` логики из роутов.
2. Разделить `health`: оставить `GET /health` чистой проверкой живости сервера (без отправки в Telegram), а Telegram-проверку сделать отдельной ручкой/командой.
3. Перейти с `serde_json::Value` на типизированные DTO для webhook payload, чтобы убрать хрупкий парсинг и повысить надёжность.
4. Добавить проверку секрета webhook (например, `X-Telegram-Bot-Api-Secret-Token`) и базовый rate limit на `/webhook/*`.
5. Вынести конфигурацию окружения в отдельную структуру с централизованной валидацией (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `HOST`, `PORT`).
6. Добавить retry с backoff и timeout для запросов в Telegram API, плюс явную обработку ошибок ответа API.
7. Добавить unit/integration тесты для публичной логики: формирование текста уведомлений, парсинг webhook, обработка ошибок Telegram.
8. Улучшить наблюдаемость: единый формат structured logs, request id, и отдельные метрики по успешным/ошибочным отправкам.
9. Добавить ограничение параллельных `/codex` задач и очередь, чтобы избежать перегрузки при burst-нагрузке.
10. Добавить graceful shutdown и корректное завершение фоновых задач при остановке сервера.
